# Magnisale

The marketing site and blog for **Magnisale**, an AI-powered business systems agency.

It is a plain static site (HTML, one CSS file and one small JS module), with no framework and no backend. The design follows the [Hermes Agent](https://hermes-agent.nousresearch.com/) landing page: Hermes blue and paper, tall condensed type, and public-domain art dithered into blue.

## Structure

```
public/                 Deploy root, served as-is. Committed, including generated HTML.
  index.html            Landing page          ← generated from src/index.html
  blog/…                Blog, posts, tag pages ← generated from posts/*.md
  404.html, sitemap.xml                        ← generated
  assets/css/site.css   The whole design system (tokens at the top)
  assets/js/site.js     Progressive enhancements (nav, menu, copy, terminal demo, parallax)
  assets/icons.svg      Icon sprite: logo, socials, pixel icons
  assets/art/           Dithered artwork      ← generated by scripts/dither-art.mjs
  assets/fonts/         Self-hosted fonts (OFL, see OFL.txt)
src/
  layout.html           Page shell
  partials/             head, header (nav, menu), footer
  index.html            Landing page content
posts/*.md              Blog posts
scripts/
  build.mjs             Builds the HTML (needs `marked`)
  serve.mjs             Local preview server (no dependencies)
  dither-art.mjs        Regenerates the artwork (needs `sharp`, see below)
```

## Commands

```bash
npm install        # installs marked, the only dependency
npm run build      # regenerate public/*.html and sitemap.xml
npm run serve      # preview at http://localhost:3000
```

Edit files in `src/` and `posts/`, not the generated HTML in `public/`. Run `npm run build` and commit the result. CSS, JS and images in `public/assets/` are edited directly.

## Writing a post

Add `posts/my-post.md`:

```markdown
---
title: "Post title"
date: "2026-11-01"
excerpt: "One or two sentences for the blog index and meta description."
tags: ["news"]
---

## Heading

Markdown body…
```

Then run `npm run build`. The post appears at `/blog/my-post/`, with tag pages, the sitemap and the footer's "Latest" links updated automatically.

## Artwork

All imagery is public domain, downloaded from Wikimedia Commons and dithered into the site palette by `scripts/dither-art.mjs`. Crops and tones are set at the top of that script. `sharp` is deliberately not a project dependency, so install it temporarily to regenerate:

```bash
npm i --no-save sharp && npm run art
```

This also renders `favicon.png`, `apple-touch-icon.png` and `og.png` from `assets/logo.svg`.

## Deploy

The site is hosted on **GitHub Pages** at `magnisale.com`. `.github/workflows/pages.yml` publishes `public/` on every push to `main`.

- In the repo settings, Pages **Source** is set to *GitHub Actions*, and the custom domain is set to `magnisale.com`.
- DNS lives at Namecheap: four `A` records on `@` point to GitHub Pages, and `www` is a CNAME to `jjokah.github.io`.
- The site uses root-relative paths (`/assets/…`), so it only renders correctly on the custom domain, not at `jjokah.github.io/magnisale/`.

`wrangler.jsonc` is an alternative setup for Cloudflare Workers. Any static host works, because `public/` is pre-built: serve that folder, with no build step.

The site has no backend: enquiries go to `hello@magnisale.com` via `mailto:` links and copy buttons.
